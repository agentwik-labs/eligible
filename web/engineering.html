A receipt checker that shows its work, and what it costs

Eligible reads a receipt, decides which lines an FSA or HSA can pay for, and cites the IRS text behind each answer. This page covers how it's built, how it's measured and what it costs per receipt. Every figure is read from a committed eval report.

02 · Pipeline

Five steps, two model calls

Only two steps call a model. The rest is plain code, which is where the guarantees live: personal data never reaches a model, and a citation the system didn't retrieve never reaches a user.

03 · Cost

Projected before the first prompt, then measured

The cost model was written before any prompt existed. Measurement then showed where the projection was wrong, and that's what decides the next optimizations.

What's built to control it

  • Exact cost per call. A Decimal price table covers cache writes (1.25× or 2×), cache reads and long-context tiers. An unknown model raises an error instead of costing $0.
  • Spend ceiling before each call. A worst-case estimate stops a run before the call that could cross the budget, and it never falls back to a cheaper model.
  • Free reruns. Answers are cached by model, prompt version and input hash, so unchanged eval cases cost $0. Truncated or refused answers are never cached.
  • Sources sent once per receipt. A chunk that several items share appears once in the decide prompt.
  • Ledger and report. Spend, savings from both caches, thinking tokens and p95 latency per prompt version, plus a flag when a "static" prompt prefix drifts.

    05 · Retrieval

    The search that failed, and the fix the eval pointed to

    The IRS sources contradict each other about the same aspirin. The two passages below are what retrieval has to tell apart.

    “Except for insulin, you can’t include in medical expenses amounts you pay for a drug that isn’t prescribed.”
    Pub 502 · the tax deduction
    “Expenses incurred for over-the-counter medicine (whether or not prescribed) and menstrual care products are considered medical care and are considered a covered expense.”
    Pub 969 · health FSAs, the rule that applies

    Ablation: recall@5 by configuration (target 90%)

    The IRS text never says "ibuprofen" or "DayQuil". It says "over-the-counter medicine", so neither keyword nor vector search links a product to that rule. The eligibility list does: each entry names products and cites the governing sections. Citation expansion follows those citations after ranking. The cross-encoder reranker lowered recall and added about 1.6 s per item, so it's off by default.
